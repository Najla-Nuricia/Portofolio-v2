## Anatomy through interaction

AR/VR Organ uses interactive 3D experiences to support learning about the human body. I designed the interface system and interaction flow for organ-focused lessons in immersive environments.

The project required readable controls, clear information hierarchy, and consistent visual feedback across Unity-based AR and VR scenes.

### What I do
- Designed a minimalist mobile UI for an AR/VR educational application, optimizing screen space and visual clarity.
- Created logos, branding elements, and custom backgrounds using Figma.
- Built a modular Unity UI system with reusable button components and dynamic color variations.
- Prepared and optimized UI assets through slicing and export workflows for Unity integration.
- Implemented UI layouts directly in Unity while maintaining design accuracy and interactivity.
- Conducted functional and regression testing for an Android-based AR educational application, covering UI, audio, animations, marker tracking, 3D model rendering, and interactive features.
- Designed and executed test cases across multiple application builds, documenting results and retesting fixes.
- Executed 252 test cases, achieving an 88% pass rate, with 27 failed, 1 blocked, and 16 not run.
- Identified 5 critical-severity test cases affecting core application functionality.
- Reported bugs with severity levels, tracked their status, and verified fixes through retesting.
- Independently fixed minor UI and functional bugs to improve application stability and user experience.
- Tested feature interactions and switching scenarios to verify functionality and identify potential issues.
