Perform manual testing, including functional, regression, smoke, and sanity testing to ensure features work as expected. Identify and document bugs with clear reproduction steps, expected and actual results, and supporting evidence. Design test cases covering positive, negative, and edge-case scenarios. Develop reusable QA templates for bug reporting and test case tracking to organize test documentation and monitor issue resolution. Conduct UI/UX testing to validate interface consistency, layout, and usability. Track test execution results, verify bug fixes through retesting, and collaborate with developers to improve software quality.
